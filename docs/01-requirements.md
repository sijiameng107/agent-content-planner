# 需求

用户是内容运营人员。目标是生成一份有素材依据、预算和模拟截止时间均可满足的活动方案。

输入 theme、budget（非负整数模拟单位）、start_time、deadline（含时区）；可选 initial_variant 指定起始方案偏好。材料为本地合成素材和工具价目/耗时表。输出包含任务计划、步骤成功/失败状态、工具结果、已花费与预计总费用、模拟完成时间、已保存方案或未完成原因。

| 验收点 | 成功标准 |
|---|---|
| 正常完成 | 费用不超预算、预计完成不晚于截止、方案真实保存 |
| 缺预算或截止时间 | 明确缺失字段、不猜测、不执行付费工具 |
| 工具失败 | 失败步骤不能标成功，已成功结果保留，调整或明确停止 |
| 预算超限 | 起始12、预算10，模型可改估8；无可行方案明确差额与未完成 |
| 重复执行 | 相同请求和资料，只保存一个方案，不重复收取成功步骤费用 |
| 失败续跑（加分） | 使用同一数据库恢复成功结果，只继续未完成步骤 |

核心范围不包括 UI、发布、生产级调度、多 Agent。时间使用合成工具耗时累加，并由显式 start_time 计算模拟完成时间，真实模型 API 等待时间不计入业务截止时间。该项目验证模拟排期可行性，不承诺真实活动执行按时完成。
