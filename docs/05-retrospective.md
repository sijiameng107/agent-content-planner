# 复盘

预算重规划的关键是区分“估算总费用”和“已发生费用”：估算12不应该扣12，再选择8时也不能重复收检索费。实现中账本只累计实际成功步骤，估算为已发生费用加剩余步骤费用；脚本生成前再次检查，防止执行过期方案。

另一个重点是失败续跑：成功检索结果和失败事件分开保存，恢复时只续做生成，不抹去历史失败；幂等键不包含故障开关，使解除故障后仍能找到原任务。约束和资料变化则创建新任务，避免错误复用旧价格或旧素材。

本次采用限时最小范围交付，完成代码、离线测试、文档和证据后冻结；不新增UI、多Agent或部署。未完成项是项目二真实模型运行、至少两条live动态路径、GitHub远程交付及个人独立验证记录。
